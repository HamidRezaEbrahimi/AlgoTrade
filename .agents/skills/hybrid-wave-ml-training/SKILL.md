# مهارت آموزش و اعتبارسنجی خودکار هیبرید الگوهای امواج الیوت (Hybrid Wave-ML Pipeline)

این مهارت به عنوان سند استاندارد و مرجع فنی جهت **استخراج ویژگی‌ها، رهگیری چرخه حیات، گریدبندی کیفی و آموزش خودکار مدل‌های یادگیری ماشین (Machine Learning)** برای الگوهای امواج الیوت (به‌ویژه الگوی رانینگ فلت - Running Flat) تدوین شده است.

---

## ۱. معماری کلی سیستم هیبرید (Hybrid Architecture)

سیستم تشخیص و معامله‌گری الگوهای موجی بر پایه یک رویکرد دو مرحله‌ای (Dual-Stage Pipeline) عمل می‌کند:

```
[ کندل‌های بازار (Multi-Timeframe) ]
                │
                ▼
┌──────────────────────────────────────────────┐
│ ۱. موتور هندسه ریاضی (AlefTrade Core)        │
│   - فیلتر زیگزاگ انطباقی (Adaptive ZigZag)   │
│   - محاسبه نسبت‌های فیبوناچی موج A/B/C       │
│   - اعتبارسنجی ارگودیک کافمن (Kaufman ER)    │
│   - ردیابی ۵ مرحله‌ای تکوین زنده موج (PRZ)   │
└──────────────────────┬───────────────────────┘
                       │ کاندیداهای معتبر هندسی
                       ▼
┌──────────────────────────────────────────────┐
│ ۲. بردارساز ویژگی‌ها (to_feature_vector)     │
│   - استخراج بردار ۷ بُعدی پیوسته عددی        │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────┐
│ ۳. مدل احتمالاتی یادگیری ماشین (AlgoTrade)   │
│   - مدل جدولی (RandomForest / LightGBM)      │
│   - تخمین احتمال برد واقعی (Win-Probability) │
│   - فال‌بک ریاضیاتی کالیبره‌شده پایدار       │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────┐
│ ۴. سرویس ضبط، گریدبندی و چرخه حیات (Recorder)│
│   - ۳ حالت کاری: خودکار / دستی / غیرفعال     │
│   - رتبه‌بندی کیفی: STRONG / NORMAL / WEAK   │
│   - مانیتورینگ نقض تراز P0 یا برخورد به TP1 │
│   - ذخیره در دیتاست و بازآموزی محلی خودکار   │
└──────────────────────────────────────────────┘
```

## ۲. ماتریس بردار ویژگی‌های استاندارد (Feature Vector Matrix)

هر الگوی تاییدشده یا در حال تکوین توسط متد `to_feature_vector()` به یک بردار عددی پیوسته با ابعاد `(1, 7)` تبدیل می‌شود:

| شاخص | نام ویژگی | محدوده مقادیر | مفهوم هندسی و آماری |
| :--- | :--- | :--- | :--- |
| **۰** | `retr_a` | $0.15 - 0.85$ | نسبت اصلاحی موج A نسبت به ایمپالس قبلی ($P0 \to P1$). زون ایده‌آل: $0.618$ |
| **۱** | `retr_b` | $1.02 - 2.50$ | نسبت انبساط موج B نسبت به موج A ($P1 \to P2$). در رانینگ فلت باید $> 1.0$ باشد. |
| **۲** | `retr_c` | $0.50 - 1.10$ | نسبت بازگشت موج C نسبت به موج B ($P2 \to P3$). در رانینگ فلت نباید به کف A برسد. |
| **۳** | `slope_ratio` | $0.50 - 3.50$ | نسبت شیب زمانی اصلاح به شیب ایمپالس قبلی ($\ge 1.0$ نشانه انباشت سالم). |
| **۴** | `er_b` | $0.05 - 0.90$ | ضریب راندمان کافمن در موج B ($\le 0.35$ بیانگر ساختار غیررونددار و اصلاحی). |
| **۵** | `chop_b` | $20.0 - 80.0$ | شاخص فشردگی (Choppiness Index) در تشکیل موج B. |
| **۶** | `dtw_score` | $0.01 - 0.50$ | فاصله انحنای زمانی پویا (Dynamic Time Warping) نسبت به الگوی ایده‌آل بنچ‌مارک. |

## ۳. قانون نقض قطعی در تراز P0 و چرخه حیات (Lifecycle Evaluation)

### قانون نقض ساختار (P0 Invalidation Guard):
در تمامی الگوهای موجی (به‌ویژه ساختارهای فلت)، نقطه آغازین چرخه یعنی **P0 خط قرمز و کف/سقف ابطال مطلق** است:
- در الگوی **صعودی (Bullish)**: اگر قیمت در هر لحظه پس از نقطه C به زیر قیمت نقطه $P0$ نفوذ کند ($Price < P0.price$)، الگو **کاملاً باطل شده (INVALIDATED)** و باید فوراً پوزیشن بسته شده یا ستاپ لغو شود.
- در الگوی **نزولی (Bearish)**: اگر قیمت در هر لحظه پس از نقطه C به بالای قیمت نقطه $P0$ نفوذ کند ($Price > P0.price$)، الگو باطل است.

### وضعیت‌های سه‌گانه چرخه حیات:
1. **فعال (ACTIVE)**: الگو تکمیل شده و در حال پیشروی به سمت تارگت‌ها است بدون اینکه تراز P0 نقض شده باشد.
2. **موفق (TARGET_HIT)**: قیمت بدون شکست تراز P0 به تارگت سود اولیه ($TP1$) یا ثانویه ($TP2$) رسیده است ($\text{Label} = 1$).
3. **فیلد / باطل‌شده (INVALIDATED)**: قیمت تراز P0 را نقض کرده و حد ضرر فعال شده است ($\text{Label} = 0$).

## ۴. سیستم رتبه‌بندی کیفی الگوها (Pattern Quality Grading - PQS)

برای ارزیابی و فیلتر کردن الگوهای باکیفیت از بین تمامی الگوهای یافت‌شده، سیستم از شاخص **Pattern Quality Score (PQS)** با مقیاس ۰ تا ۱۰۰ استفاده می‌کند:

```
PQS = Fibo_Score(30) + Noise_Score(30) + Slope_Score(20) + RR_Score(20)
```

### تفکیک امتیازدهی:
1. **انطباق فیبوناچی موج‌ها (۳۰ امتیاز)**:
   - موج A در زون $0.58 - 0.68$: ۱۰ امتیاز کامل
   - موج B در زون $1.20 - 1.30$: ۱۰ امتیاز کامل
   - موج C در زون $0.75 - 0.90$: ۱۰ امتیاز کامل
2. **تمیزی فرم و شاخص نویز کافمن و DTW (۳۰ امتیاز)**:
   - ضریب کارایی $ER_B \le 0.25$: ۱۵ امتیاز کامل
   - انطباق فرمی $DTW \le 0.08$: ۱۵ امتیاز کامل
3. **شتاب و شیب انباشت زمانی (۲۰ امتیاز)**:
   - نسبت شیب اصلاح به رانه $SlopeRatio \ge 1.3$: ۲۰ امتیاز کامل
4. **نسبت ریسک به ریوارد (۲۰ امتیاز)**:
   - نسبت $R:R \ge 2.5$: ۲۰ امتیاز کامل ($R:R \ge 2.0$: ۱۶ امتیاز)

### سطوح گرید کیفی (Grades):
- 🟢 **قوی (STRONG / Grade A)**: امتیاز $\ge 80$ (سبز زمردی `#10b981`)
- 🔵 **نرمال (NORMAL / Grade B)**: امتیاز بین $55$ تا $79$ (آبی `#3b82f6`)
- 🟡 **ضعیف (WEAK / Grade C)**: امتیاز $< 55$ (کهربایی `#f59e0b`)

## ۵. حالات سه‌گانه ضبط الگوها (Pattern Recording Modes)

سیستم ذخیره‌سازی داده‌های یادگیری ماشین دارای ۳ حالت تنظیمی است:

1. **حالت خودکار (`auto`)**:
   - به محض شناسایی هر الگوی جدید یا به‌روزرسانی وضعیت چرخه حیات (از ACTIVE به TARGET_HIT یا INVALIDATED)، رکورد به صورت بلادرنگ و با جلوگیری از تکرار (Deduplication) در پایگاه داده ذخیره می‌شود.
2. **حالت دستی (`manual`)**:
   - الگوهای روی چارت فقط زمانی در بانک داده ذخیره می‌شوند که کاربر در دراور مشخصات الگو دکمه «ذخیره در بانک الگوها» را کلیک کند.
3. **حالت غیرفعال (`disabled`)**:
   - کلیه عملیات‌های ضبط و ذخیره‌سازی خاموش است.

> **تغییر حالت:** کاربر می‌تواند این حالت را از طریق مدال تنظیمات الگوها در چارت یا از طریق فراخوانی اندپوینت `POST /api/patterns/recorder/config` تغییر دهد.

## ۶. گردش کار آموزش محلی مدل (Local Training Workflow)

### گام اول: اجرای اسکریپت آموزش از خط فرمان
برای بازآموزی مدل یادگیری ماشین با جدیدترین الگوهای ثبت‌شده در دیتابیس لوکال:

```powershell
cd g:\Projects\AlgoTrade\backend
.venv\Scripts\python scripts/train_wave_ml.py
```

### گام دوم: فراخوانی از طریق REST API
پلتفرم همچنین امکان تریگر کردن بازآموزی مدل از طریق وب‌سرویس را فراهم می‌کند:

```http
POST /api/patterns/train
```

### خروجی‌های آموزش:
1. مدل یادگیری ماشین در مسیر `app/ml/models/running_flat_scorer.joblib` به‌روزرسانی می‌شود.
2. گزارش ارزیابی (Classification Report) شامل Precision، Recall و F1-Score در خروجی لاگ ثبت می‌شود.
3. اهمیت ویژگی‌ها (Feature Importances) چاپ شده و مدل بلادرنگ بدون نیاز به ریستارت سرور وارد چرخه استنتاج زنده می‌شود.
